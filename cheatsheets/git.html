Git — دستورات کنترل نسخه

از نصب و تنظیم تا branch، merge، remote و undo — با جستجو و فیلتر

۵دسته‌بندی
۲۵دستور
🔍قابل جستجو
🔍
sudo apt install gitSETUP
نصب git روی Ubuntu
git config --global user.name "نام"SETUP
تنظیم نام کاربری برای همه پروژه‌ها
git config --global user.email "ایمیل"SETUP
تنظیم ایمیل (باید با GitHub یکسان باشد)
git config --listSETUP
نمایش تمام تنظیمات فعلی
git initLOCAL
ایجاد مخزن git در پوشه فعلی
git statusLOCAL
وضعیت فایل‌ها — تغییر یافته، staged، untracked
git add <file>LOCAL
افزودن فایل به staging area برای commit
git add .LOCAL
افزودن همه تغییرات به staging
git commit -m "پیام"LOCAL
ذخیره تغییرات staged با پیام توصیفی
git log --onelineLOCAL
مشاهده تاریخچه commit‌ها به صورت فشرده
git diffLOCAL
مشاهده تفاوت بین نسخه‌های فایل
git branchBRANCH
لیست تمام شاخه‌های محلی
git checkout -b <name>BRANCH
ساخت شاخه جدید و رفتن به آن
git switch <branch>BRANCH
رفتن به شاخه دیگر (روش مدرن‌تر)
git merge <branch>BRANCH
ادغام یک شاخه در شاخه فعلی
git stashBRANCH
ذخیره موقت تغییرات ناتمام
git branch -d <name>BRANCH
حذف شاخه پس از merge
git clone <url>REMOTE
کپی مخزن از GitHub یا سرور ریموت
git remote add origin <url>REMOTE
اتصال مخزن محلی به ریموت
git push origin <branch>REMOTE
ارسال commit‌های محلی به ریموت
git pullREMOTE
دریافت و ادغام تغییرات از ریموت
git fetchREMOTE
دریافت تغییرات ریموت بدون ادغام
git restore <file>UNDO
بازگشت فایل به حالت آخرین commit
git reset --soft HEAD~1UNDO
برگشت از آخرین commit با حفظ تغییرات
git reset --hard HEAD~1UNDO
برگشت کامل — تغییرات حذف می‌شوند
git revert <hash>UNDO
ایجاد commit معکوس — ایمن‌ترین روش
git commit --amendUNDO
ویرایش آخرین commit — پیام یا محتوا
نتیجه‌ای یافت نشد 🔍
